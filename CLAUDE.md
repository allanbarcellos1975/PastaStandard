# Instruções para Claude Code — PastaStandard

@AGENTS.md

O arquivo AGENTS.md contém o protocolo obrigatório de desenvolvimento, segurança, autorização, Git e Supabase. Ler integralmente antes de qualquer alteração, juntamente com CONTRIBUTING.md e instruções específicas do diretório em que se atua.

- Iniciar por inspeção e plano; não editar arquivos nem executar operações de escrita antes da autorização do responsável.
- Utilizar branch exclusiva a partir da main oficial atual. Nunca escrever na main, integrar PR ou publicar sem a autorização correspondente.
- Usar comandos de leitura e ferramentas com as menores permissões necessárias. Não contornar prompts de autorização, proteções GitHub ou restrições do ambiente.
- Não executar comandos SQL ou ações no Supabase de produção sem aprovação específica. Nunca exibir credenciais ou enviar arquivos ignorados.
- Não substituir o trabalho existente do notebook, nem usar os repositórios .old como base oficial. Em caso de conflito, parar e informar.
- Apresentar evidências dos testes realmente executados, limitações e plano de reversão antes de pedir autorização para merge.
